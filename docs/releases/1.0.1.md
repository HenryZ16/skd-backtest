## 更新内容

1. **修正 IR 公式**：按比赛文档描述，将信息比率改为 `IR = Annualized Excess Return / Tracking Error`。年化超额收益率取组合与基准各自年化收益率之差；跟踪误差为日主动收益的样本标准差乘以年化因子。跟踪误差为零或必要数据无效时，IR 为空。
2. **调整 RankIC 计算逻辑**：至少有两只有效配对股票、且 score 全部相等时，RankIC 记为 0，并参与汇总。有效配对不足两只，或 score 有差异但收益标签全部相等时，仍记为空；RankIC 标准差为零时，RankICIR 仍为空。
3. **引入后复权回测涨跌停限制**：涨停时禁止买入，跌停时禁止卖出，另一方向按正常交易规则处理。强制读取 `MarketDataRawOpen`，结合历史后复权收盘价和 `Factor33_winsor.is_st` 推算限价，不提供开关。支持主板、科创板、创业板的历史涨跌幅比例及 ST 规则，原始价格按最小报价单位 0.01 元四舍五入后换算至后复权价格。该单一 raw open 数据仅用于后复权限价推算，真实价格回测与标签路径不变。

限价目前采用估算方案，未覆盖新股上市、重新上市、退市整理等特殊交易安排；数据要求和边界见[使用说明](https://github.com/HenryZ16/skd-backtest/blob/v1.0.1/docs/usage.md#数据约定)。升级后需在 `data_dir` 下提供 `MarketDataRawOpen` 数据目录。

## 安装

需要 Python 3.11 及以上。发行包不包含回测数据。

pip：

```powershell
python -m pip install --upgrade "https://github.com/HenryZ16/skd-backtest/releases/download/v1.0.1/skd_backtest-1.0.1-py3-none-any.whl"
```

uv（Windows / PowerShell）：

```powershell
uv venv .venv
uv pip install --python .venv --upgrade "https://github.com/HenryZ16/skd-backtest/releases/download/v1.0.1/skd_backtest-1.0.1-py3-none-any.whl"
```

已有符合版本要求的 `.venv` 时，可跳过创建环境。

附件提供 wheel 和源码分发包，均包含 Apache License 2.0 许可证。
