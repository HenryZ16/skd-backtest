## 更新

相较 `0.1.0b2`：

- 统一从 `data_dir` 读取数据，删除数据能力声明和独立来源配置，并自动识别价格来源。
- 支持直接读取沪深300原生权重及行业数据，按日归一化权重并校验历史成分。
- 优化器仅保留 Top-K 和 Barra，Barra 改为基于排序信号与暴露约束的线性优化。
- 删除协方差、特异风险、风险厌恶系数及因子列表配置，并默认安装 SciPy。
- 每次回测必须读取 `HS300_index`，统一计算基准净值、超额收益、跟踪误差和信息比率。
- 将持仓估值和收盘报表改为数组批量计算，提升回测速度并保持核算结果一致。
- 使用 Typeguard 检查推理输入和返回类型，无需修改用户模型声明。
- 新增 Barra 使用示例，完善安装、配置、接口及设计文档。

## 安装

需要 Python 3.11 及以上。

pip：

```powershell
python -m pip install "https://github.com/HenryZ16/skd-backtest/releases/download/v1.0.0rc1/skd_backtest-1.0.0rc1-py3-none-any.whl"
```

uv：

```powershell
uv venv .venv
uv pip install --python .venv "https://github.com/HenryZ16/skd-backtest/releases/download/v1.0.0rc1/skd_backtest-1.0.0rc1-py3-none-any.whl"
```
