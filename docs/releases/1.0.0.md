skd-backtest 1.0.0 是项目的首个正式版本，面向沪深300指数增强研究与模型统一评测。
从模型输出的股票得分出发，框架完成组合构建、下一交易日开盘执行、逐日估值和绩效评价，
让不同模型在相同数据与交易规则下进行比较。

## 主要能力

- **两种接入方式**：通过 Python API 回测自己的模型，或通过命令行加载标准 `inference.py` 与 `model/` 提交包。
- **按时点提供数据**：按历史交易日推进，模型仅接收截至信号日可见的研究窗口，调仓在下一交易日开盘执行。
- **统一组合构建**：提供 Top-K 等权组合与 Barra 暴露约束优化，支持单股权重、主动权重、行业、风格及换手限制。
- **交易与账户核算**：支持后复权收益模式，以及具备所需数据时的真实价格模式；真实价格模式支持 T+1、整手买入、停牌和涨跌停限制。
- **预测与投资表现评价**：输出 RankIC、年化超额收益、跟踪误差、信息比率等 15 项原始指标，并生成指标 JSON、七张审计 CSV 和运行日志。
- **连续数据回放**：支持分批读取、后台预取与异步推理，提供进度显示和结果表。

## 安装

需要 Python 3.11 及以上。**本项目及发行包不提供回测数据，使用者需自行准备。** 使用前请按[使用说明](https://github.com/HenryZ16/skd-backtest/blob/v1.0.0/docs/usage.md)配置数据和模型。

pip：

```powershell
python -m pip install "https://github.com/HenryZ16/skd-backtest/releases/download/v1.0.0/skd_backtest-1.0.0-py3-none-any.whl"
skd-backtest-evaluate --version
```

uv（Windows / PowerShell）：

```powershell
uv venv .venv
uv pip install --python .venv "https://github.com/HenryZ16/skd-backtest/releases/download/v1.0.0/skd_backtest-1.0.0-py3-none-any.whl"
.\.venv\Scripts\skd-backtest-evaluate.exe --version
```

macOS / Linux 的命令入口为 `.venv/bin/skd-backtest-evaluate`。版本查询输出为 `skd-backtest-evaluate 1.0.0`。
